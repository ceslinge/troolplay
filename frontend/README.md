# Frontend

Interface web de TroolPlay, en React, TypeScript et Vite.

## Lancer en local

Le backend doit tourner à côté : Vite transmet les requêtes `/api` à `http://127.0.0.1:8000`.

    npm install
    npm run dev

Puis ouvrir http://localhost:5173.

## Vérifier avant une PR

    npm run lint
    npm run build
